# Superstore Sales Trend Analysis

## Objective
Analyze changes in business sales over time using Tableau Public.

## Dataset
Superstore Sales Dataset from Kaggle.

## Tools Used
- Tableau Public
- Microsoft Excel / CSV
- GitHub

## Main Measure
Sales

## Date Field
Order Date

## Visualizations
1. Monthly Sales Trend - Line Chart
2. Sales by Category - Bar Chart
3. Sales by Region - Bar Chart
4. Profit by Category - Bar Chart
5. Sales by Segment - Pie Chart

## Interactive Filter
Region

## Business Insights
- Sales vary across different time periods.
- Some periods show higher sales than others.
- Product categories contribute differently to total sales.
- Regional sales performance varies.
- Profit performance differs across categories.

## Recommendations
- Prepare sufficient inventory during high-demand periods.
- Focus marketing efforts on high-performing categories and regions.
